# Учебный склад (1С)

Учебный проект для демонстрации базового складского учета в 1С:Предприятии.

## Что есть в проекте

- справочники номенклатуры и складов;
- документы поступления и расхода товаров;
- регистр накопления остатков по складу и номенклатуре;
- отчет «Остатки на складах» на СКД;
- обработка тестового заполнения данными.

## Как открыть

Это исходники конфигурации 1С, а не самостоятельное Windows-приложение. Для просмотра и запуска нужны платформа 1С:Предприятие и 1C:EDT.

1. Распакуйте архив.
2. Импортируйте каталог `src` в 1C:EDT как проект конфигурации.
3. Обновите конфигурацию информационной базы и запустите приложение из EDT.
4. Для тестовых данных откройте обработку «Тестовое заполнение склада» и нажмите кнопку заполнения.

Названия пунктов меню могут отличаться между версиями EDT. Перед запуском на рабочей базе проверьте конфигурацию на отдельной учебной информационной базе.

## Состав

Исходники объектов конфигурации находятся в `src/`: метаданные `.mdo`, модули 1С `.bsl`, формы и схема компоновки данных `.dcs`.

## Публикация на GitHub

Для публикации создайте репозиторий и загрузите содержимое архива. ZIP также можно приложить к GitHub Release. Формат `.exe` для этого исходного проекта не подходит: исполняемая среда предоставляется платформой 1С.
